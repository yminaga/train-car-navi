# スムーズ乗換 Navi (SmoothNavi) 🚃💨

電車移動の際に、**「どの号車・何番ドアに乗れば、乗り換えや目的地の出口が一番スムーズか」** を自分で自由にルート設定して記録・管理できるPWA対応Webアプリケーションです。

スマホ片手でもパッと見やすく、電車が来る直前や乗車中でも瞬時に確認できるUIデザインを採用しています。

---

## 🌟 主な機能

### 1. 🛠 自由なルート設定・ビルダー（手動ルート作成）
- **タイトルの設定**: 「自宅 ➔ オフィス（朝通勤）」「新宿 ➔ 渋谷」など、よく使う移動の名前を自由に設定（簡単入力チップ付き）。
- **分類タグ**: 通勤、休日、お出かけ、通学、出張、その他。
- **乗り換えステップ（区間）の自由追加**:
  - 第1走、第2走、第3走…と「＋ 次の乗り換え電車を追加」ボタンで直感的にステップを増やせます。
  - **路線名**: 山手線、中央線、銀座線、丸ノ内線、東横線などのワンタップ入力チップ付き。
  - **乗車駅 ➔ 降車駅**: 自由に入力可能。乗り換え追加時は前の降車駅が自動で次の乗車駅に引き継がれます。
  - **号車番号**: 1〜15号車をボタングリッドでワンタップ選択。
  - **ドア番号・位置**: 「1番ドア」「2番ドア」「前寄り」「中央」「後ろ寄り」などのワンタップチップ ＋ 自由入力。
  - **スムーズ理由**: 「階段正面」「上りエスカレーター前」「エレベーター至近」「改札出口直結」「乗換通路すぐ」などのクイックタグ。
  - **区間メモ**: 「降りたら右手の階段へ」などの自由な補足を記録可能。

### 2. 📋 マイメモ一覧・管理
- 保存したメモはブラウザの `localStorage` に自動保存され、リロードしても消えません。
- **ピン留め機能**: よく使うルートを常に一覧の最上部に固定。
- **リアルタイム検索 & タグフィルター**: 駅名や路線名、タグですぐに絞り込み可能。
- **編集機能**: カードの鉛筆アイコンを押すと、作成画面にデータが読み込まれていつでも内容を調整できます。
- **共有テキストコピー**: LINEやメモ帳に「[1] 山手線 👉 4号車 2番ドア」と送れるワンタップコピー機能。
- **Yahoo!乗換案内リンク**: 現在の電車の時刻表や遅延状況を調べたい時にワンタップで外部連携。
- **バックアップ機能**: JSON形式でのエクスポート＆インポートに対応。

### 3. 📱 乗車中モード（特大HUD）⚡
- 電車のホームや混雑した車内でも片手で確認できるよう、カードの「乗車中モード」をタップすると全画面の高コントラスト画面が起動。
- **超特大フォント（70〜80px）で号車番号とドア番号を表示**。
- 電車編成のどの位置に乗っているかが図解で一目でわかります。
- 複数乗り換えがある場合も「次の乗り換えへ」ボタンでサクサク切り替え可能。

### 4. 📲 スマホアプリ風 PWA (Progressive Web App) 対応
- スマホの「ホーム画面に追加」を行うことで、アドレスバーのない全画面ネイティブアプリとして起動します。
- `sw.js` (Service Worker) によるオフラインキャッシュにより、電波の届かない地下鉄の駅でも爆速で起動・閲覧できます。

## 🚀 起動方法

### 方法A: すぐに試す（ブラウザで直接開く）
- `index.html` をダブルクリックして開きます。
- 通常のWebサイトとして全機能（ルート作成、メモ保存、乗車中モードなど）がそのまま動作します。

### 方法B: PWA（アプリ化・オフライン機能）として動かす
1. フォルダ内の **`run-server.bat`** をダブルクリックして実行します。
2. ブラウザで以下のURLを開きます：
   ```
   http://localhost:8000
   ```
3. 画面上部の**「インストール」**ボタンを押すか、ブラウザの「ホーム画面に追加」を実行すると、PCやスマホにアプリとしてインストールされます！
